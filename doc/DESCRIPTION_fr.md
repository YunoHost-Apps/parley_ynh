Parley est un serveur de discussion qui parle IRC, tout simplement. N'importe
quel client IRC peut s'y connecter, et les instances se fédèrent entre elles :
une personne d'un serveur peut rejoindre un canal hébergé sur un autre, où elle
apparaît sous la forme `pseudo:domaine`.

L'interface web sert à administrer l'instance et à créer les jetons avec
lesquels les clients IRC se connectent. Ce n'est volontairement pas un client de
discussion : discuter, c'est le travail du client IRC.

Ce paquet installe `parleyd` (le serveur) et `parleyctl` (le client en ligne de
commande utilisé pour l'administration) à partir de la version binaire publiée
en amont.
